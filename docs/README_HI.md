शुद्ध Python में लिखा गया 《पीपल्स डेली》 के इलेक्ट्रॉनिक संस्करण का स्वचालित डाउनलोड और विलय टूल। PDF पृष्ठ डाउनलोड, लेख पाठ निष्कर्षण (TXT/DOC/DOCX), दिनांक श्रेणी बैच डाउनलोड, और पूर्ण कॉन्फ़िगरेशन का समर्थन करता है। किसी ब्राउज़र या ड्राइवर की आवश्यकता नहीं है।

---

## विशेषताएँ

- **PDF मोड**: वर्तमान दिन के सभी पृष्ठ PDF को स्वचालित रूप से डाउनलोड करता है और उन्हें एक पूर्ण फ़ाइल में विलय करता है
- **पाठ मोड**: सभी पृष्ठों के लेख पाठ को निष्कर्षित करता है और `TXT` / `DOC` / `DOCX` में आउटपुट करता है (शून्य अतिरिक्त निर्भरता)
- **both मोड**: PDF और पाठ संस्करण दोनों को एक साथ उत्पन्न करता है
- **बैच डाउनलोड**: दिनांक श्रेणी अभिव्यक्ति का समर्थन करता है; प्रति दिन अलग विलय या सभी पृष्ठों को एक क्रॉस-दिनांक बड़ी फ़ाइल में विलय
- **पूर्ण कॉन्फ़िगरेशन**: 30+ कॉन्फ़िगरेशन विकल्प (नेटवर्क, इंटरफ़ेस, आउटपुट, गति सीमा, प्रॉक्सी, शेड्यूलिंग आदि) `config.json` के माध्यम से समायोज्य
- **स्वचालित निर्भरता स्थापना**: पहली बार चलाने पर `pypdf` विलय लाइब्रेरी को स्वचालित रूप से स्थापित करता है (आधिकारिक स्रोत → त्सिंघुआ मिरर पर फॉलबैक)
- **रियल-टाइम प्रगति**: डाउनलोड प्रगति बार, गति प्रदर्शन, पूरा होने पर फ़ाइल स्थान स्वचालित रूप से खुलता है
- **मज़बूत त्रुटि प्रबंधन**: नेटवर्क पुनः प्रयास, फ़ाइल कब्जे पर स्वचालित पुनः प्रयास, भविष्य की दिनांक/अमान्य दिनांक/अमान्य अभिव्यक्ति अवरोधन, उपयोगकर्ता के अनुकूल त्रुटि संदेश

## त्वरित आरंभ

### विधि 1: BAT पर डबल-क्लिक (Windows उपयोगकर्ताओं के लिए अनुशंसित)

1. सुनिश्चित करें कि Python स्थापित है और PATH में जोड़ा गया है (या `py` लॉन्चर उपलब्ध है)
2. `下载人民日报.bat` पर डबल-क्लिक करें
3. संकेतों के अनुसार दिनांक दर्ज करें (Enter = आज), प्रारूप चुनें (T / PDF / B)
4. डाउनलोड और विलय की प्रतीक्षा करें; पूरा होने पर फ़ाइल स्थान स्वचालित रूप से खुलता है

### विधि 2: कमांड लाइन

```bash
# एकल दिन PDF (डिफ़ॉल्ट आज)
python rmrb_downloader.py

# निर्दिष्ट दिनांक + प्रारूप
python rmrb_downloader.py 20260903 pdf
python rmrb_downloader.py 20260903 text
python rmrb_downloader.py 20260903 both

# बैच डाउनलोड (दिनांक श्रेणी, प्रति दिन अलग विलय)
python rmrb_downloader.py --batch "20260901-20260903" pdf --merge-mode each

# बैच डाउनलोड (सभी को एक क्रॉस-दिनांक बड़ी फ़ाइल में विलय)
python rmrb_downloader.py --batch "20260901-20260903,20260905" both --merge-mode all

# किसी दिनांक से आज तक (दायाँ छोर खाली)
python rmrb_downloader.py --batch "20260801-" pdf

# डिफ़ॉल्ट कॉन्फ़िगरेशन उत्पन्न/ताज़ा करें
python rmrb_downloader.py --init

# दैनिक स्वचालित डाउनलोड अनुसूचित कार्य पंजीकृत/हटाएँ
python rmrb_downloader.py --task-install
python rmrb_downloader.py --task-remove
```

## कॉन्फ़िगरेशन विवरण (config.json)

पहली बार चलाने पर `config.json` स्वचालित रूप से उत्पन्न होता है। सभी कॉन्फ़िगरेशन विकल्प और उनका अर्थ:

### क्रॉलिंग और नेटवर्क

| कुंजी | प्रकार | डिफ़ॉल्ट मान | विवरण |
|---|---|---|---|
| `base_url` | string | `http://paper.people.com.cn/rmrb/pc` | पीपल्स डेली इलेक्ट्रॉनिक संस्करण आधार पता |
| `rate_limit_kbps` | number | `0` | डाउनलोड गति सीमा (KB/s), `0` = असीमित |
| `timeout` | int | `30` | एकल नेटवर्क अनुरोध समयसमाप्ति (सेकंड) |
| `retry` | int | `3` | विफलता पर पुनः प्रयास संख्या |
| `retry_interval` | float | `2.0` | पुनः प्रयास अंतराल (सेकंड) |
| `request_interval` | float | `0.2` | प्रत्येक अनुरोध के बीच अंतराल (सेकंड), बहुत बार पहुँच से रोकता है |
| `concurrent` | int | `1` | समवर्ती डाउनलोड थ्रेड संख्या (1–16) |
| `proxy` | string | `""` | HTTP/HTTPS प्रॉक्सी पता, खाली = कोई प्रॉक्सी नहीं |
| `user_agent` | string | Chrome UA | अनुरोध User-Agent |

### इंटरफ़ेस

| कुंजी | प्रकार | डिफ़ॉल्ट मान | विवरण |
|---|---|---|---|
| `color_foreground` | string | `"A"` | cmd अग्रभूमि रंग (0–F हेक्साडेसिमल) |
| `color_background` | string | `"0"` | cmd पृष्ठभूमि रंग (0–F हेक्साडेसिमल) |
| `window_title` | string | `人民日报电子版下载器` | कंसोल विंडो शीर्षक |
| `show_progress` | bool | `true` | डाउनलोड प्रगति बार दिखाएँ या नहीं |

### दिनांक और सामग्री

| कुंजी | प्रकार | डिफ़ॉल्ट मान | विवरण |
|---|---|---|---|
| `default_date` | string | `""` | डिफ़ॉल्ट दिनांक `YYYYMMDD`, खाली = आज |
| `default_format` | string | `"pdf"` | डिफ़ॉल्ट प्रारूप: `pdf` / `text` / `both` |
| `edition_filter` | list | `[]` | **पृष्ठ श्वेतसूची**: गैर-खाली होने पर केवल सूचीबद्ध पृष्ठ संख्याएँ डाउनलोड करें (उदा. `[1,2]` = केवल पृष्ठ 1 और 2); खाली = सभी पृष्ठ |
| `holiday_skip` | bool | `false` | एकल दिन मोड में कोई पृष्ठ नहीं होने पर चुपचाप छोड़ें (त्रुटि के बजाय 0 लौटाएँ) |

### बैच डाउनलोड

| कुंजी | प्रकार | डिफ़ॉल्ट मान | विवरण |
|---|---|---|---|
| `batch_enable` | bool | `false` | `true` होने पर BAT डबल-क्लिक **बैच डाउनलोड इंटरफ़ेस** दिखाता है |
| `batch_merge_mode` | string | `"each"` | `each` = प्रति दिन अलग विलय; `all` = सभी दिनांकों को एक बड़ी फ़ाइल में विलय |
| `download_path` | string | `""` | डाउनलोड रूट निर्देशिका; खाली = स्क्रिप्ट फ़ोल्डर; सापेक्ष पथ स्क्रिप्ट निर्देशिका के सापेक्ष, पूर्ण पथ भी स्वीकार्य |

### आउटपुट और विलय

| कुंजी | प्रकार | डिफ़ॉल्ट मान | विवरण |
|---|---|---|---|
| `download_dir` | string | `"pdfs_{date}"` | एकल-पृष्ठ PDF भंडारण निर्देशिका टेम्पलेट, `{date}` दिनांक से प्रतिस्थापित |
| `merged_filename` | string | `"人民日报-{date}-完整版"` | विलय PDF फ़ाइल नाम टेम्पलेट (एक्सटेंशन के बिना) |
| `auto_merge` | bool | `true` | एकल दिन मोड में स्वचालित विलय |
| `keep_singles` | bool | `true` | विलय के बाद एकल-पृष्ठ PDF निर्देशिका रखें; `false` = सफल विलय के बाद स्वचालित हटाना |
| `open_folder_after` | bool | `true` | पूरा होने पर फ़ाइल स्थान स्वचालित रूप से खोलें |

### पाठ आउटपुट

| कुंजी | प्रकार | डिफ़ॉल्ट मान | विवरण |
|---|---|---|---|

| `text_filename` | string | `"人民日报-{date}-文字版"` | पाठ संस्करण फ़ाइल नाम टेम्पलेट (एक्सटेंशन के बिना) |

|---|---|---|---|

### शेड्यूलिंग

| कुंजी | प्रकार | डिफ़ॉल्ट मान | विवरण |

## बैच डाउनलोड विवरण

### दिनांक श्रेणी अभिव्यक्ति

BAT बैच इंटरफ़ेस में या `--batch` तर्क के साथ दर्ज करें। अल्पविराम से अलग कई खंड:

| अभिव्यक्ति | अर्थ |
|---|---|
| `20260901-20260903` | 2026-09-01 से 2026-09-03 (दोनों छोर सम्मिलित) |
| `20260905` | केवल 2026-09-05 |
| `20260801-` | 2026-08-01 से **आज** तक (दायाँ छोर खाली) |
| `20260901-20260903,20260905` | श्रेणी + एकल दिन संयोजन (स्वचालित डिडुप, दिनांक क्रम में छँटाई) |

- दिनांकें वास्तव में मौजूद दिनांकें होनी चाहिए (उदा. `20260134`, `20261301` अवरुद्ध और त्रुटि के साथ सूचित)
- प्रारंभ दिनांक समाप्ति दिनांक के बाद होने पर त्रुटि
- बिना पृष्ठ की दिनांकें (गैर-प्रकाशित/गैर-जारी) स्वचालित रूप से छोड़ दी जाती हैं और सारांश में गिनी जाती हैं

### विलय मोड

| मोड | व्यवहार | उत्पन्न फ़ाइल नाम उदाहरण |
|---|---|---|
| `each` | प्रत्येक दिनांक के लिए अलग डाउनलोड, अलग विलय | `人民日报-2026-09-02-完整版.pdf`, `人民日报-2026-09-03-完整版.pdf` |
| `all` | सभी दिनांकों के सभी पृष्ठ **एक क्रॉस-दिनांक बड़ी फ़ाइल** में विलय | `人民日报-2026-09-02-2026-09-03-完整版.pdf` |

पाठ संस्करण भी `each` / `all` का समर्थन करता है।

### BAT बैच इंटरफ़ेस सक्षम करें

`config.json` संपादित करें, `"batch_enable"` को `true` पर सेट करें। BAT पर डबल-क्लिक बैच डाउनलोड इंटरफ़ेस में प्रवेश करता है (श्रेणी दर्ज करें → विलय मोड चुनें → प्रारूप चुनें)。

## पाठ संस्करण आउटपुट प्रारूप

| प्रारूप | विवरण | निर्भरता |
|---|---|---|
| `TXT` | UTF-8 सादा पाठ, पृष्ठ शीर्षक और लेख पाठ शामिल | कोई नहीं |
| `DOC` | HTML सामग्री `.doc` के रूप में सहेजी गई, Microsoft Word / WPS से सीधे खोली जा सकती है | कोई नहीं |
| `DOCX` | मानक OOXML (`zipfile` के साथ न्यूनतम दस्तावेज़ संरचना हस्तलिखित), Word/WPS/LibreOffice से खोली जा सकती है | कोई नहीं |

`config.json` में `"text_output_format": "DOCX"` आदि सेट करके स्विच करें।

## सामान्य त्रुटियाँ और समाधान

| त्रुटि संदेश | कारण | समाधान |
|---|---|---|
| `未来日期，人民日报尚未出版` | आज के बाद की दिनांक दर्ज की गई | दिनांक जाँचें, या `default_date` संशोधित करें |
| `日期不存在（月份或日期越界）` | उदा. `20261301`, `20260134` | वास्तव में मौजूद दिनांक दर्ज करें |
| `日期应为 8 位数字 YYYYMMDD` | दिनांक अंकों की संख्या गलत है | `YYYYMMDD` प्रारूप में दर्ज करें, उदा. `20260903` |
| `未找到任何版面` | दिनांक गैर-प्रकाशित/गैर-जारी, या `edition_filter` ने पृष्ठ खाली कर दिए, या नेटवर्क विसंगति | कार्यदिवस दिनांक पर बदलें; `edition_filter` जाँचें; ऊपर `[网络]` संकेत जाँचें |
| `无法安装合并库 pypdf` | नेटवर्क अनुपलब्ध, pip के माध्यम से स्थापना असंभव | मैन्युअल रूप से `pip install pypdf` चलाएँ, या प्रॉक्सी कॉन्फ़िगर करने के बाद पुनः प्रयास करें |
| `合并失败：目标文件正被占用` | समान नाम PDF PDF रीडर / एक्सप्लोरर पूर्वावलोकन में खुला है | खुली समान नाम फ़ाइल बंद करें और पुनः प्रयास करें, या `merged_filename` / `download_path` संशोधित करें |
| `域名解析失败 / 网络连接失败` | नेटवर्क कनेक्टेड नहीं, DNS विसंगति या प्रॉक्सी त्रुटि | नेटवर्क जाँचें; `config.json` का `proxy` कॉन्फ़िगरेशन जाँचें |
| `连接/读取超时` | नेटवर्क धीमा या सर्वर प्रतिक्रिया धीमी | `timeout` बढ़ाएँ (उदा. 60), बाद में पुनः प्रयास करें |
| `服务器返回 HTTP 403/429` | बहुत बार पहुँच, दर सीमा | `request_interval` बढ़ाएँ (उदा. 1.0), `concurrent` घटाएँ |
| `日期表达式错误：无效日期` | बैच अभिव्यक्ति में अमान्य दिनांक शामिल | `YYYYMMDD` प्रारूप में दर्ज करें, अल्पविराम से कई श्रेणियाँ अलग करें |
| `格式参数应为 text / pdf / both` | प्रारूप तर्क गलत है | `text` / `pdf` / `both` उपयोग करें (BAT इंटरफ़ेस: T / PDF / B) |
| `--merge-mode 应为 each / all` | विलय मोड तर्क गलत है | `each` या `all` उपयोग करें |
