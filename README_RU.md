Инструмент для автоматической загрузки и объединения электронной версии газеты «Жэньминь жибао», написанный на чистом Python. Поддерживает загрузку страниц PDF, извлечение текста статей (TXT/DOC/DOCX), пакетную загрузку по диапазонам дат и полную настройку. Не требует браузера или драйверов.

---

## Возможности

- **Режим PDF**: автоматически загружает все страницы PDF текущего дня и объединяет их в один полный файл
- **Текстовый режим**: извлекает текст всех статей и выводит в формате `TXT` / `DOC` / `DOCX` (без дополнительных зависимостей)
- **Режим both**: одновременно генерирует PDF-версию и текстовую версию
- **Пакетная загрузка**: поддерживает выражения диапазонов дат; отдельное объединение по каждой дате или объединение всех страниц в один большой междатный файл
- **Полная настройка**: более 30 параметров конфигурации (сеть, интерфейс, вывод, ограничение скорости, прокси, планирование и т.д.) настраиваются через `config.json`
- **Автоматическая установка зависимостей**: автоматически устанавливает библиотеку объединения `pypdf` при первом запуске (официальный источник → резервный зеркало Цинхуа)
- **Прогресс в реальном времени**: полоса прогресса загрузки, отображение скорости, автоматическое открытие расположения файла по завершении
- **Надёжная обработка ошибок**: повторные попытки сети, автоматические повторные попытки при занятом файле, блокировка будущих дат/недопустимых дат/недопустимых выражений, понятные сообщения об ошибках

## Быстрый старт

### Способ 1: двойной клик по BAT (рекомендуется для пользователей Windows)

1. Убедитесь, что Python установлен и добавлен в PATH (или доступен запускатель `py`)
2. Дважды кликните по `下载人民日报.bat`
3. Введите дату согласно подсказкам (Enter = сегодня), выберите формат (T / PDF / B)
4. Дождитесь загрузки и объединения; расположение файла откроется автоматически по завершении

### Способ 2: командная строка

```bash
# PDF за один день (по умолчанию сегодня)
python rmrb_downloader.py

# Указанная дата + формат
python rmrb_downloader.py 20260903 pdf
python rmrb_downloader.py 20260903 text
python rmrb_downloader.py 20260903 both

# Пакетная загрузка (диапазон дат, отдельное объединение по каждой дате)
python rmrb_downloader.py --batch "20260901-20260903" pdf --merge-mode each

# Пакетная загрузка (всё объединено в один большой междатный файл)
python rmrb_downloader.py --batch "20260901-20260903,20260905" both --merge-mode all

# С определённой даты до сегодняшнего дня (правый конец пуст)
python rmrb_downloader.py --batch "20260801-" pdf

# Создать/обновить конфигурацию по умолчанию
python rmrb_downloader.py --init

# Зарегистрировать/удалить запланированную задачу для ежедневной автоматической загрузки
python rmrb_downloader.py --task-install
python rmrb_downloader.py --task-remove
```

## Описание конфигурации (config.json)

`config.json` автоматически генерируется при первом запуске. Все параметры конфигурации и их значения:

### Краулинг и сеть

| Ключ | Тип | Значение по умолчанию | Описание |
|---|---|---|---|
| `base_url` | string | `http://paper.people.com.cn/rmrb/pc` | Базовый адрес электронной версии газеты «Жэньминь жибао» |
| `rate_limit_kbps` | number | `0` | Ограничение скорости загрузки (КБ/с), `0` = без ограничений |
| `timeout` | int | `30` | Таймаут для одного сетевого запроса (секунды) |
| `retry` | int | `3` | Количество повторных попыток при сбое |
| `retry_interval` | float | `2.0` | Интервал между повторными попытками (секунды) |
| `request_interval` | float | `0.2` | Интервал между каждым запросом (секунды), предотвращает блокировку из-за слишком частого доступа |
| `concurrent` | int | `1` | Количество одновременных потоков загрузки (1–16) |
| `proxy` | string | `""` | Адрес HTTP/HTTPS прокси, пусто = без прокси |
| `user_agent` | string | Chrome UA | User-Agent запросов |

### Интерфейс

| Ключ | Тип | Значение по умолчанию | Описание |
|---|---|---|---|
| `color_foreground` | string | `"A"` | Цвет переднего плана cmd (0–F шестнадцатеричное) |
| `color_background` | string | `"0"` | Цвет фона cmd (0–F шестнадцатеричное) |
| `window_title` | string | `人民日报电子版下载器` | Заголовок окна консоли |
| `show_progress` | bool | `true` | Показывать полосу прогресса загрузки или нет |

### Дата и контент

| Ключ | Тип | Значение по умолчанию | Описание |
|---|---|---|---|
| `default_date` | string | `""` | Дата по умолчанию `YYYYMMDD`, пусто = сегодня |
| `default_format` | string | `"pdf"` | Формат по умолчанию: `pdf` / `text` / `both` |
| `edition_filter` | list | `[]` | **Белый список страниц**: если не пуст, загружаются только указанные номера страниц (например `[1,2]` = только страницы 1 и 2); пусто = все страницы |
| `holiday_skip` | bool | `false` | В режиме одного дня молча пропускать, если страниц нет (возвращает 0 вместо ошибки) |

### Пакетная загрузка

| Ключ | Тип | Значение по умолчанию | Описание |
|---|---|---|---|
| `batch_enable` | bool | `false` | Если `true`, двойной клик по BAT показывает **интерфейс пакетной загрузки** |
| `batch_merge_mode` | string | `"each"` | `each` = отдельное объединение по каждой дате; `all` = объединение всех дат в один большой файл |
| `download_path` | string | `""` | Корневой каталог загрузки; пусто = папка скрипта; относительный путь относительно каталога скрипта, абсолютный путь также допустим |

### Вывод и объединение

| Ключ | Тип | Значение по умолчанию | Описание |
|---|---|---|---|
| `download_dir` | string | `"pdfs_{date}"` | Шаблон каталога для хранения одностраничных PDF, `{date}` заменяется на дату |
| `merged_filename` | string | `"人民日报-{date}-完整版"` | Шаблон имени файла объединённого PDF (без расширения) |
| `auto_merge` | bool | `true` | Автоматическое объединение в режиме одного дня |
| `keep_singles` | bool | `true` | Сохранять каталог одностраничных PDF после объединения; `false` = автоматическое удаление после успешного объединения |
| `open_folder_after` | bool | `true` | Автоматически открывать расположение файла по завершении |

### Текстовый вывод

| Ключ | Тип | Значение по умолчанию | Описание |
|---|---|---|---|
| `text_output_format` | string | `"TXT"` | Формат вывода текстовой версии: `TXT` / `DOC` / `DOCX` |
| `text_filename` | string | `"人民日报-{date}-文字版"` | Шаблон имени файла текстовой версии (без расширения) |
| `text_include_edition` | bool | `true` | Включать разделители заголовков страниц в текстовую версию или нет |

### Журнал и уведомления

| Ключ | Тип | Значение по умолчанию | Описание |
|---|---|---|---|
| `log_file` | string | `"rmrb_download.log"` | Имя файла журнала; пусто = без журнала |
| `log_level` | string | `"normal"` | Уровень журнала: `quiet` / `normal` / `debug` |
| `beep_on_done` | bool | `false` | Звуковой сигнал по завершении |
| `msg_on_done` | bool | `false` | Показывать окно сообщения Windows по завершении |

### Планирование

| Ключ | Тип | Значение по умолчанию | Описание |
|---|---|---|---|
| `auto_run` | bool | `false` | Включить ежедневную автоматическую загрузку (требуется предварительная регистрация запланированной задачи с помощью `--task-install`) |
| `auto_run_time` | string | `"08:00"` | Время ежедневного автоматического выполнения `HH:MM` |

> Недопустимые значения конфигурации (такие как отрицательное ограничение скорости, конкурентность вне диапазона, недопустимые коды цветов) автоматически откатываются к значениям по умолчанию при запуске и печатают предупреждение, без сбоя.

## Подробности пакетной загрузки

### Выражение диапазона дат

Вводится в интерфейсе пакетной загрузки BAT или с аргументом `--batch`. Несколько сегментов, разделённых запятыми:

| Выражение | Значение |
|---|---|
| `20260901-20260903` | 2026-09-01 по 2026-09-03 (включая оба конца) |
| `20260905` | Только 2026-09-05 |
| `20260801-` | 2026-08-01 по **сегодняшний день** (правый конец пуст) |
| `20260901-20260903,20260905` | Комбинация диапазона + отдельного дня (автоматическое удаление дубликатов, сортировка по дате) |

- Даты должны быть реально существующими датами (например `20260134`, `20261301` блокируются и сообщаются об ошибке)
- Дата начала после даты окончания вызывает ошибку
- Даты без страниц (не опубликовано/не вышло) автоматически пропускаются и учитываются в сводке

### Режим объединения

| Режим | Поведение | Пример имени сгенерированного файла |
|---|---|---|
| `each` | Отдельная загрузка и объединение для каждой даты | `人民日报-2026-09-02-完整版.pdf`, `人民日报-2026-09-03-完整版.pdf` |
| `all` | Все страницы всех дат объединены в **один большой междатный файл** | `人民日报-2026-09-02-2026-09-03-完整版.pdf` |

Текстовая версия также поддерживает `each` / `all`.

### Включить интерфейс пакетной загрузки BAT

Отредактируйте `config.json`, установите `"batch_enable"` в `true`. Двойной клик по BAT входит в интерфейс пакетной загрузки (ввод диапазона → выбор режима объединения → выбор формата).

## Форматы вывода текстовой версии

| Формат | Описание | Зависимость |
|---|---|---|
| `TXT` | Обычный текст UTF-8, включает заголовки страниц и текст статей | нет |
| `DOC` | HTML-контент, сохранённый как `.doc`, открывается напрямую в Microsoft Word / WPS | нет |
| `DOCX` | Стандартный OOXML (минимальная структура документа, написанная вручную с помощью `zipfile`), открывается в Word/WPS/LibreOffice | нет |

Переключите формат, установив `"text_output_format": "DOCX"` и т.д. в `config.json`.

## Распространённые ошибки и решения

| Сообщение об ошибке | Причина | Решение |
|---|---|---|
| `未来日期，人民日报尚未出版` | Введена дата после сегодняшнего дня | Проверьте дату или отредактируйте `default_date` |
| `日期不存在（月份或日期越界）` | например `20261301`, `20260134` | Введите реально существующую дату |
| `日期应为 8 位数字 YYYYMMDD` | Неправильное количество цифр даты | Введите в формате `YYYYMMDD`, например `20260903` |
| `未找到任何版面` | Дата не опубликована/не вышла, или `edition_filter` опустошил страницы, или сетевая аномалия | Перейдите на дату рабочего дня; проверьте `edition_filter`; ознакомьтесь с подсказкой `[网络]` выше |
| `无法安装合并库 pypdf` | Сеть недоступна, невозможно установить через pip | Выполните вручную `pip install pypdf` или повторите попытку после настройки прокси |
| `合并失败：目标文件正被占用` | PDF с тем же именем открыт в PDF-ридере / предпросмотре Explorer | Закройте открытый файл с тем же именем и повторите попытку, или отредактируйте `merged_filename` / `download_path` |
| `域名解析失败 / 网络连接失败` | Сеть не подключена, DNS-аномалия или ошибка прокси | Проверьте сеть; проверьте конфигурацию `proxy` в `config.json` |
| `连接/读取超时` | Медленная сеть или медленный ответ сервера | Увеличьте `timeout` (например 60), повторите попытку позже |
| `服务器返回 HTTP 403/429` | Слишком частый доступ, ограничение скорости | Увеличьте `request_interval` (например 1.0), уменьшите `concurrent` |
| `日期表达式错误：无效日期` | Пакетное выражение содержит недопустимую дату | Введите в формате `YYYYMMDD`, разделите несколько диапазонов запятыми |
| `格式参数应为 text / pdf / both` | Неправильный аргумент формата | Используйте `text` / `pdf` / `both` (интерфейс BAT: T / PDF / B) |
| `--merge-mode 应为 each / all` | Неправильный аргумент режима объединения | Используйте `each` или `all` |

- Авторские права на газету «Жэньминь жибао» принадлежат издательству газеты «Жэньминь жибао». Загруженный контент должен соответствовать соответствующим законам и условиям использования веб-сайта.
