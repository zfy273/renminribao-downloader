# เครื่องมือดาวน์โหลดและรวมฉบับอิเล็กทรอนิกส์หนังสือพิมพ์ประชาชน / People's Daily Downloader

เครื่องมือดาวน์โหลดและรวมฉบับอิเล็กทรอนิกส์ของ 《หนังสือพิมพ์ประชาชน》 โดยเขียนด้วย Python บริสุทธิ์ รองรับการดาวน์โหลดหน้า PDF, การดึงข้อความบทความ (TXT/DOC/DOCX), การดาวน์โหลดเป็นชุดตามช่วงวันที่, และการกำหนดค่าที่สมบูรณ์ ไม่จำเป็นต้องใช้เบราว์เซอร์หรือไดรเวอร์

---

## คุณสมบัติ

- **โหมด PDF**: ดาวน์โหลด PDF ทุกหน้าของวันปัจจุบันโดยอัตโนมัติและรวมเป็นไฟล์ฉบับสมบูรณ์ไฟล์เดียว
- **โหมดข้อความ**: ดึงข้อความบทความจากทุกหน้าและส่งออกเป็น `TXT` / `DOC` / `DOCX` (ไม่มีการพึ่งพาเพิ่มเติม)
- **โหมด both**: สร้างทั้งเวอร์ชัน PDF และข้อความพร้อมกัน
- **ดาวน์โหลดเป็นชุด**: รองรับนิพจน์ช่วงวันที่; รวมแยกตามวันหรือรวมทุกหน้าเป็นไฟล์ขนาดใหญ่ข้ามวัน
- **การกำหนดค่าที่สมบูรณ์**: ตัวเลือกการกำหนดค่ามากกว่า 30 รายการ (เครือข่าย, อินเทอร์เฟซ, เอาต์พุต, ขีดจำกัดความเร็ว, พร็อกซี, การกำหนดเวลา ฯลฯ) ปรับได้ผ่าน `config.json`
- **การติดตั้งการพึ่งพาอัตโนมัติ**: ติดตั้งไลบรารีรวม `pypdf` โดยอัตโนมัติเมื่อเรียกใช้ครั้งแรก (แหล่งที่มาอย่างเป็นทางการ → fallback ที่กระจก Tsinghua)
- **ความคืบหน้าแบบเรียลไทม์**: แถบความคืบหน้าการดาวน์โหลด, แสดงความเร็ว, เปิดตำแหน่งไฟล์โดยอัตโนมัติเมื่อเสร็จสิ้น
- **การจัดการข้อผิดพลาดที่มีประสิทธิภาพ**: ลองใหม่เครือข่าย, ลองใหม่อัตโนมัติเมื่อไฟล์ถูกใช้งาน, บล็อกวันที่ในอนาคต/วันที่ไม่ถูกต้อง/นิพจน์ไม่ถูกต้อง, ข้อความแจ้งข้อผิดพลาดที่เป็นมิตร

### ไลบรารีที่ต้องพึ่งพา

## เริ่มต้นอย่างรวดเร็ว

### วิธีที่ 1: ดับเบิลคลิก BAT (แนะนำสำหรับผู้ใช้ Windows)

1. ตรวจสอบว่าติดตั้ง Python แล้วและเพิ่มใน PATH (หรือมีตัวเรียกใช้ `py`)
2. ดับเบิลคลิก `下载人民日报.bat`
3. ป้อนวันที่ตามคำแจ้ง (Enter = วันนี้), เลือกรูปแบบ (T / PDF / B)
4. รอการดาวน์โหลดและการรวม; ตำแหน่งไฟล์จะเปิดโดยอัตโนมัติเมื่อเสร็จสิ้น

### วิธีที่ 2: คอมมานด์ไลน์

```bash
# PDF วันเดียว (ค่าเริ่มต้นวันนี้)
python rmrb_downloader.py

# วันที่ระบุ + รูปแบบ
python rmrb_downloader.py 20260903 pdf
python rmrb_downloader.py 20260903 text
python rmrb_downloader.py 20260903 both

# ดาวน์โหลดเป็นชุด (ช่วงวันที่, รวมแยกตามวัน)
python rmrb_downloader.py --batch "20260901-20260903" pdf --merge-mode each

# ดาวน์โหลดเป็นชุด (รวมทั้งหมดเป็นไฟล์ขนาดใหญ่ข้ามวัน)
python rmrb_downloader.py --batch "20260901-20260903,20260905" both --merge-mode all

# จากวันที่หนึ่งถึงวันนี้ (ปลายขวาว่าง)
python rmrb_downloader.py --batch "20260801-" pdf

# สร้าง/รีเฟรชการกำหนดค่าเริ่มต้น
python rmrb_downloader.py --init

# ลงทะเบียน/ลบงานที่กำหนดเวลาสำหรับการดาวน์โหลดอัตโนมัติประจำวัน
python rmrb_downloader.py --task-install
python rmrb_downloader.py --task-remove
```

## คำอธิบายการกำหนดค่า (config.json)

`config.json` ถูกสร้างขึ้นโดยอัตโนมัติเมื่อเรียกใช้ครั้งแรก ตัวเลือกการกำหนดค่าทั้งหมดและความหมาย:

### การครอลและเครือข่าย

| คีย์ | ประเภท | ค่าเริ่มต้น | คำอธิบาย |
|---|---|---|---|
| `base_url` | string | `http://paper.people.com.cn/rmrb/pc` | ที่อยู่ฐานของฉบับอิเล็กทรอนิกส์หนังสือพิมพ์ประชาชน |
| `rate_limit_kbps` | number | `0` | ขีดจำกัดความเร็วดาวน์โหลด (KB/s), `0` = ไม่จำกัด |
| `timeout` | int | `30` | หมดเวลาสำหรับคำขอเครือข่ายเดียว (วินาที) |
| `retry` | int | `3` | จำนวนครั้งที่ลองใหม่เมื่อล้มเหลว |
| `retry_interval` | float | `2.0` | ระยะห่างระหว่างการลองใหม่ (วินาที) |
| `request_interval` | float | `0.2` | ระยะห่างระหว่างแต่ละคำขอ (วินาที), ป้องกันการถูกบล็อกจากการเข้าถึงบ่อยเกินไป |
| `concurrent` | int | `1` | จำนวนเธรดดาวน์โหลดพร้อมกัน (1–16) |
| `proxy` | string | `""` | ที่อยู่พร็อกซี HTTP/HTTPS, ว่าง = ไม่ใช้พร็อกซี |
| `user_agent` | string | Chrome UA | User-Agent ของคำขอ |

### อินเทอร์เฟซ

| คีย์ | ประเภท | ค่าเริ่มต้น | คำอธิบาย |
|---|---|---|---|
| `color_foreground` | string | `"A"` | สีพื้นหน้าของ cmd (0–F ฐานสิบหก) |
| `color_background` | string | `"0"` | สีพื้นหลังของ cmd (0–F ฐานสิบหก) |
| `window_title` | string | `人民日报电子版下载器` | ชื่อหน้าต่างคอนโซล |
| `show_progress` | bool | `true` | แสดงแถบความคืบหน้าการดาวน์โหลดหรือไม่ |

### วันที่และเนื้อหา

| คีย์ | ประเภท | ค่าเริ่มต้น | คำอธิบาย |
|---|---|---|---|
| `default_date` | string | `""` | วันที่เริ่มต้น `YYYYMMDD`, ว่าง = วันนี้ |
| `default_format` | string | `"pdf"` | รูปแบบเริ่มต้น: `pdf` / `text` / `both` |
| `edition_filter` | list | `[]` | **รายการขาวของหน้า**: ถ้าไม่ว่าง จะดาวน์โหลดเฉพาะหมายเลขหน้าที่ระบุ (เช่น `[1,2]` = เฉพาะหน้า 1 และ 2); ว่าง = ทุกหน้า |
| `holiday_skip` | bool | `false` | ในโหมดวันเดียว ข้ามอย่างเงียบๆ ถ้าไม่มีหน้า (ส่งคืน 0 แทนข้อผิดพลาด) |

### ดาวน์โหลดเป็นชุด

| คีย์ | ประเภท | ค่าเริ่มต้น | คำอธิบาย |
|---|---|---|---|
| `batch_enable` | bool | `false` | ถ้า `true` การดับเบิลคลิก BAT จะแสดง **อินเทอร์เฟซดาวน์โหลดเป็นชุด** |
| `batch_merge_mode` | string | `"each"` | `each` = รวมแยกตามวัน; `all` = รวมทุกวันเป็นไฟล์ขนาดใหญ่ไฟล์เดียว |
| `download_path` | string | `""` | ไดเรกทอรีรากของการดาวน์โหลด; ว่าง = โฟลเดอร์ของสคริปต์; เส้นทางสัมพัทธ์อ้างอิงจากไดเรกทอรีสคริปต์, เส้นทางสัมบูรณ์ก็ใช้ได้ |

### เอาต์พุตและการรวม

| คีย์ | ประเภท | ค่าเริ่มต้น | คำอธิบาย |
|---|---|---|---|
| `download_dir` | string | `"pdfs_{date}"` | เทมเพลตไดเรกทอรีจัดเก็บ PDF หน้าเดียว, `{date}` ถูกแทนที่ด้วยวันที่ |
| `merged_filename` | string | `"人民日报-{date}-完整版"` | เทมเพลตชื่อไฟล์ PDF ที่รวมแล้ว (ไม่รวมนามสกุล) |
| `auto_merge` | bool | `true` | รวมอัตโนมัติในโหมดวันเดียว |
| `keep_singles` | bool | `true` | เก็บไดเรกทอรี PDF หน้าเดียวไว้หลังการรวม; `false` = ลบอัตโนมัติหลังการรวมสำเร็จ |
| `open_folder_after` | bool | `true` | เปิดตำแหน่งไฟล์โดยอัตโนมัติเมื่อเสร็จสิ้น |

### เอาต์พุตข้อความ

| คีย์ | ประเภท | ค่าเริ่มต้น | คำอธิบาย |
|---|---|---|---|
| `text_output_format` | string | `"TXT"` | รูปแบบเอาต์พุตของเวอร์ชันข้อความ: `TXT` / `DOC` / `DOCX` |
| `text_filename` | string | `"人民日报-{date}-文字版"` | เทมเพลตชื่อไฟล์ของเวอร์ชันข้อความ (ไม่รวมนามสกุล) |
| `text_include_edition` | bool | `true` | รวมตัวคั่นชื่อหน้าในเวอร์ชันข้อความหรือไม่ |

### บันทึกและการแจ้งเตือน

| คีย์ | ประเภท | ค่าเริ่มต้น | คำอธิบาย |
|---|---|---|---|
| `log_file` | string | `"rmrb_download.log"` | ชื่อไฟล์บันทึก; ว่าง = ไม่บันทึก |
| `log_level` | string | `"normal"` | ระดับบันทึก: `quiet` / `normal` / `debug` |
| `beep_on_done` | bool | `false` | ส่งเสียงบี๊บเมื่อเสร็จสิ้น |
| `msg_on_done` | bool | `false` | แสดงกล่องข้อความ Windows เมื่อเสร็จสิ้น |

### การกำหนดเวลา

| คีย์ | ประเภท | ค่าเริ่มต้น | คำอธิบาย |
|---|---|---|---|
| `auto_run` | bool | `false` | เปิดใช้งานการดาวน์โหลดอัตโนมัติประจำวัน (ต้องลงทะเบียนงานที่กำหนดเวลาด้วย `--task-install` ก่อน) |
| `auto_run_time` | string | `"08:00"` | เวลาทำงานอัตโนมัติประจำวัน `HH:MM` |

> ค่าการกำหนดค่าที่ไม่ถูกต้อง (เช่น ขีดจำกัดความเร็วเป็นลบ, การทำงานพร้อมกันนอกช่วง, รหัสสีที่ไม่ถูกต้อง) จะถูกคืนค่าเป็นค่าเริ่มต้นโดยอัตโนมัติเมื่อเริ่มต้นและพิมพ์คำเตือน โดยไม่ทำให้เกิด crash

## รายละเอียดการดาวน์โหลดเป็นชุด

### นิพจน์ช่วงวันที่

ป้อนในอินเทอร์เฟซชุด BAT หรือกับอาร์กิวเมนต์ `--batch` แยกหลายส่วนด้วยเครื่องหมายจุลภาค:

| นิพจน์ | ความหมาย |
|---|---|
| `20260901-20260903` | 2026-09-01 ถึง 2026-09-03 (รวมทั้งสองขอบ) |
| `20260905` | เฉพาะ 2026-09-05 |
| `20260801-` | 2026-08-01 ถึง **วันนี้** (ปลายขวาว่าง) |
| `20260901-20260903,20260905` | ช่วง + วันเดียวรวมกัน (ลบซ้ำอัตโนมัติ, เรียงลำดับตามวันที่) |

- วันที่ต้องเป็นวันที่มีอยู่จริง (เช่น `20260134`, `20261301` จะถูกบล็อกและแจ้งข้อผิดพลาด)
- วันที่เริ่มต้นหลังวันที่สิ้นสุดจะทำให้เกิดข้อผิดพลาด
- วันที่ไม่มีหน้า (ไม่เผยแพร่/ไม่ออก) จะถูกข้ามโดยอัตโนมัติและนับเข้าในสรุป

### โหมดการรวม

| โหมด | พฤติกรรม | ตัวอย่างชื่อไฟล์ที่สร้าง |
|---|---|---|
| `each` | ดาวน์โหลดและรวมแยกกันสำหรับแต่ละวัน | `人民日报-2026-09-02-完整版.pdf`, `人民日报-2026-09-03-完整版.pdf` |
| `all` | รวมทุกหน้าของทุกวันเป็น **ไฟล์ขนาดใหญ่ข้ามวันไฟล์เดียว** | `人民日报-2026-09-02-2026-09-03-完整版.pdf` |

เวอร์ชันข้อความรองรับ `each` / `all` เช่นกัน

### เปิดใช้งานอินเทอร์เฟซชุด BAT

แก้ไข `config.json`, ตั้งค่า `"batch_enable"` เป็น `true` การดับเบิลคลิก BAT จะเข้าสู่อินเทอร์เฟซดาวน์โหลดเป็นชุด (ป้อนช่วง → เลือกโหมดการรวม → เลือกรูปแบบ)

## รูปแบบเอาต์พุตเวอร์ชันข้อความ

| รูปแบบ | คำอธิบาย | การพึ่งพา |
|---|---|---|
| `TXT` | ข้อความล้วน UTF-8, รวมชื่อหน้าและข้อความบทความ | ไม่มี |
| `DOC` | เนื้อหา HTML บันทึกเป็น `.doc`, เปิดได้โดยตรงด้วย Microsoft Word / WPS | ไม่มี |
| `DOCX` | OOXML มาตรฐาน (เขียนโครงสร้างเอกสารขั้นต่ำด้วยตนเองด้วย `zipfile`), เปิดได้ด้วย Word/WPS/LibreOffice | ไม่มี |

สลับรูปแบบโดยตั้งค่า `"text_output_format": "DOCX"` ฯลฯ ใน `config.json`

| ข้อความแจ้งข้อผิดพลาด | สาเหตุ | วิธีแก้ไข |
|---|---|---|
| `未来日期，人民日报尚未出版` | ป้อนวันที่หลังวันนี้ | ตรวจสอบวันที่ หรือแก้ไข `default_date` |
| `日期不存在（月份或日期越界）` | เช่น `20261301`, `20260134` | ป้อนวันที่มีอยู่จริง |
| `日期应为 8 位数字 YYYYMMDD` | จำนวนหลักของวันที่ไม่ถูกต้อง | ป้อนในรูปแบบ `YYYYMMDD`, เช่น `20260903` |
| `未找到任何版面` | วันที่ไม่เผยแพร่/ไม่ออก, หรือ `edition_filter` ทำให้หน้าว่างเปล่า, หรือเครือข่ายผิดปกติ | เปลี่ยนเป็นวันทำการ; ตรวจสอบ `edition_filter`; ดูคำแจ้ง `[网络]` ข้างต้น |
| `无法安装合并库 pypdf` | เครือข่ายไม่พร้อมใช้งาน, ไม่สามารถติดตั้งผ่าน pip | รัน `pip install pypdf` ด้วยตนเอง หรือลองใหม่หลังกำหนดค่าพร็อกซี |
| `合并失败：目标文件正被占用` | PDF ชื่อเดียวกันกำลังเปิดอยู่ในเครื่องอ่าน PDF / ตัวอย่าง Explorer | ปิดไฟล์ชื่อเดียวกันที่เปิดอยู่แล้วลองใหม่ หรือแก้ไข `merged_filename` / `download_path` |
| `域名解析失败 / 网络连接失败` | เครือข่ายไม่ได้เชื่อมต่อ, DNS ผิดปกติ หรือพร็อกซีผิดพลาด | ตรวจสอบเครือข่าย; ตรวจสอบการกำหนดค่า `proxy` ใน `config.json` |
| `连接/读取超时` | เครือข่ายช้าหรือเซิร์ฟเวอร์ตอบสนองช้า | เพิ่ม `timeout` (เช่น 60), ลองใหม่ในภายหลัง |
| `服务器返回 HTTP 403/429` | เข้าถึงบ่อยเกินไป, ถูกจำกัดอัตรา | เพิ่ม `request_interval` (เช่น 1.0), ลด `concurrent` |
| `日期表达式错误：无效日期` | นิพจน์ชุดมีวันที่ไม่ถูกต้อง | ป้อนในรูปแบบ `YYYYMMDD`, แยกหลายช่วงด้วยเครื่องหมายจุลภาค |
| `格式参数应为 text / pdf / both` | อาร์กิวเมนต์รูปแบบไม่ถูกต้อง | ใช้ `text` / `pdf` / `both` (อินเทอร์เฟซ BAT: T / PDF / B) |
| `--merge-mode 应为 each / all` | อาร์กิวเมนต์โหมดการรวมไม่ถูกต้อง | ใช้ `each` หรือ `all` |

## โครงสร้างโครงการ

```
rmrb_download/
├── rmrb_downloader.py      # สคริปต์หลัก (การกำหนดค่าที่สมบูรณ์ + ชุด + PDF/ข้อความ)
├── 下载人民日报.bat          # ตัวเรียกใช้งาน Windows ดับเบิลคลิก (อินเทอร์เฟซวันเดียว/ชุด)
├── build_bat.py             # ตัวสร้าง BAT (การเข้ารหัส GBK)
├── config.json              # ไฟล์การกำหนดค่า (สร้างโดยอัตโนมัติเมื่อเรียกใช้ครั้งแรก)
├── create_shortcut.ps1      # สคริปต์สร้างทางลัดเดสก์ท็อป (รวม ICO)
├── 人民日报下载器.ico        # ไอคอนหลายขนาด (16–256)
├── icon_src.png             # รูปภาพต้นทางของไอคอน
├── test_errors.py           # การทดสอบการจัดการข้อผิดพลาดและขอบเขต
├── test_download.py         # การทดสอบครบถ้วนสำหรับการดาวน์โหลดจริง
├── rmrb_download.log        # บันทึกการทำงาน (สร้างโดยอัตโนมัติ)
└── pdfs_YYYYMMDD/           # ไดเรกทอรี PDF หน้าเดียว (เก็บไว้เมื่อ keep_singles=true)
```

## การทดสอบ

```bash
# การทดสอบการจัดการข้อผิดพลาดและขอบเขต (ไม่มีการดาวน์โหลด, รวดเร็วในวินาที)
python test_errors.py

# การทดสอบครบถ้วนสำหรับการดาวน์โหลดจริง (ใช้ edition_filter เพื่อเก็บเฉพาะหน้า 1 เพื่อความเร็ว, ครอบคลุมวันเดียว/ชุด/ทุกรูปแบบ)
python test_download.py
```

การครอบคลุมการทดสอบ: วันที่ในอนาคต/วันที่ไม่ถูกต้อง/รูปแบบไม่ถูกต้อง/การวิเคราะห์นิพจน์ชุด/การตรวจสอบ config/PDF วันเดียว/TXT/DOC/DOCX/both/ชุด each/all/ไวยากรณ์ถึงวันนี้/keep_singles/การตรวจสอบชื่อไฟล์และจำนวนหน้า

## ข้อจำกัดความรับผิดชอบ

- เครื่องมือนี้ **ใช้ได้เฉพาะสำหรับการเรียนรู้และการวิจัยส่วนบุคคล**, ไม่สามารถใช้เพื่อกิจการเชิงพาณิชย์ใดๆ
- ลิขสิทธิ์ของ 《หนังสือพิมพ์ประชาชน》 เป็นของสำนักพิมพ์หนังสือพิมพ์ประชาชน เนื้อหาที่ดาวน์โหลดได้ต้องปฏิบัติตามกฎหมายที่เกี่ยวข้องและข้อกำหนดการใช้งานเว็บไซต์
- โปรดควบคุมความถี่ของการเข้าถึง (`request_interval`) อย่างเหมาะสมเพื่อหลีกเลี่ยงการสร้างภาระให้กับเว็บไซต์อย่างเป็นทางการ
- หากโครงสร้างของเว็บไซต์อย่างเป็นทางการเปลี่ยนแปลง เครื่องมือนี้อาจต้องมีการปรับเปลี่ยนตาม
