أداة لتنزيل ودمج النسخة الإلكترونية من 《صحيفة الشعب اليومية》 مكتوبة بلغة Python النقية. تدعم تنزيل صفحات PDF، واستخراج نصوص المقالات (TXT/DOC/DOCX)، والتنزيل المجمّع لنطاقات التواريخ، والتكوين الكامل. لا تتطلب أي متصفح أو برنامج تشغيل.

---

## الميزات

- **وضع PDF**: ينزّل تلقائياً جميع صفحات PDF لليوم الحالي ويدمجها في ملف واحد كامل
- **وضع النص**: يستخرج نصوص جميع المقالات ويصدرها بتنسيق `TXT` / `DOC` / `DOCX` (بدون أي تبعيات إضافية)
- **وضع both**: ينشئ في نفس الوقت النسخة PDF والنسخة النصية
- **التنزيل المجمّع**: يدعم تعبيرات نطاق التواريخ؛ الدمج المنفصل لكل تاريخ أو دمج جميع الصفحات في ملف واحد كبير عبر التواريخ
- **التكوين الكامل**: أكثر من 30 خيار تكوين (الشبكة، الواجهة، الإخراج، حد السرعة، الوكيل، الجدولة، إلخ) قابل للتعديل عبر `config.json`
- **التثبيت التلقائي للتبعيات**: يثبّت تلقائياً مكتبة الدمج `pypdf` عند أول تشغيل (المصدر الرسمي → النسخ الاحتياطي على مرآة تسينغهوا)
- **التقدم في الوقت الفعلي**: شريط تقدم التنزيل، عرض السرعة، فتح موقع الملف تلقائياً عند الانتهاء
- **معالجة قوية للأخطاء**: إعادة محاولة الشبكة، إعادة محاولة تلقائية عند احتلال الملف، حظر التواريخ المستقبلية/التواريخ غير الصالحة/التعبيرات غير الصالحة، رسائل خطأ سهلة الاستخدام

### المكتبات التابعة

| المكتبة | الغرض | طريقة التثبيت |
|---|---|---|

## البدء السريع

### الطريقة 1: النقر المزدوج على BAT (موصى به لمستخدمي Windows)

1. تأكد من تثبيت Python وإضافته إلى PATH (أو توفر مشغل `py`)
2. انقر نقراً مزدوجاً على `下载人民日报.bat`
3. أدخل التاريخ حسب المطالبات (Enter = اليوم)، اختر التنسيق (T / PDF / B)
4. انتظر التنزيل والدمج؛ سيتم فتح موقع الملف تلقائياً عند الانتهاء

### الطريقة 2: سطر الأوامر

```bash
# PDF ليوم واحد (الافتراضي اليوم)
python rmrb_downloader.py

# تاريخ محدد + تنسيق
python rmrb_downloader.py 20260903 pdf
python rmrb_downloader.py 20260903 text
python rmrb_downloader.py 20260903 both

# تنزيل مجمّع (نطاق تواريخ، دمج منفصل لكل تاريخ)
python rmrb_downloader.py --batch "20260901-20260903" pdf --merge-mode each

# تنزيل مجمّع (دمج كل شيء في ملف واحد كبير عبر التواريخ)
python rmrb_downloader.py --batch "20260901-20260903,20260905" both --merge-mode all

# من تاريخ إلى اليوم (الطرف الأيمن فارغ)
python rmrb_downloader.py --batch "20260801-" pdf

# إنشاء/تحديث التكوين الافتراضي
python rmrb_downloader.py --init

# تسجيل/إزالة مهمة مجدولة للتنزيل التلقائي اليومي
python rmrb_downloader.py --task-install
python rmrb_downloader.py --task-remove
```

## وصف التكوين (config.json)

يتم إنشاء `config.json` تلقائياً عند أول تشغيل. جميع خيارات التكوين ومعانيها:

### الزحف والشبكة

| المفتاح | النوع | القيمة الافتراضية | الوصف |
|---|---|---|---|
| `base_url` | string | `http://paper.people.com.cn/rmrb/pc` | العنوان الأساسي للنسخة الإلكترونية لصحيفة الشعب اليومية |
| `rate_limit_kbps` | number | `0` | حد سرعة التنزيل (KB/s)، `0` = غير محدود |
| `timeout` | int | `30` | مهلة طلب شبكة واحد (ثوانٍ) |
| `retry` | int | `3` | عدد مرات إعادة المحاولة عند الفشل |
| `retry_interval` | float | `2.0` | الفاصل الزمني بين إعادة المحاولات (ثوانٍ) |
| `request_interval` | float | `0.2` | الفاصل الزمني بين كل طلب (ثوانٍ)، يمنع الحظر بسبب الوصول المتكرر جداً |
| `concurrent` | int | `1` | عدد سلاسل التنزيل المتزامنة (1–16) |
| `proxy` | string | `""` | عنوان الوكيل HTTP/HTTPS، فارغ = لا وكيل |
| `user_agent` | string | Chrome UA | User-Agent للطلبات |

### الواجهة

| المفتاح | النوع | القيمة الافتراضية | الوصف |
|---|---|---|---|
| `color_foreground` | string | `"A"` | لون المقدمة لـ cmd (0–F سداسي عشري) |
| `color_background` | string | `"0"` | لون الخلفية لـ cmd (0–F سداسي عشري) |
| `window_title` | string | `人民日报电子版下载器` | عنوان نافذة وحدة التحكم |
| `show_progress` | bool | `true` | عرض شريط تقدم التنزيل أم لا |

### التاريخ والمحتوى

| المفتاح | النوع | القيمة الافتراضية | الوصف |
|---|---|---|---|
| `default_date` | string | `""` | التاريخ الافتراضي `YYYYMMDD`، فارغ = اليوم |
| `default_format` | string | `"pdf"` | التنسيق الافتراضي: `pdf` / `text` / `both` |
| `edition_filter` | list | `[]` | **القائمة البيضاء للصفحات**: إذا لم تكن فارغة، يتم تنزيل أرقام الصفحات المدرجة فقط (مثل `[1,2]` = الصفحتان 1 و 2 فقط)؛ فارغة = جميع الصفحات |
| `holiday_skip` | bool | `false` | في وضع يوم واحد، تخطي بهدوء إذا لم تكن هناك صفحات (إرجاع 0 بدلاً من خطأ) |

### التنزيل المجمّع

| المفتاح | النوع | القيمة الافتراضية | الوصف |
|---|---|---|---|
| `batch_enable` | bool | `false` | إذا كان `true`، فإن النقر المزدوج على BAT يعرض **واجهة التنزيل المجمّع** |
| `batch_merge_mode` | string | `"each"` | `each` = دمج منفصل لكل تاريخ؛ `all` = دمج جميع التواريخ في ملف كبير واحد |
| `download_path` | string | `""` | الدليل الجذري للتنزيل؛ فارغ = مجلد السكربت؛ المسار النسبي بالنسبة إلى دليل السكربت، المسار المطلق مقبول أيضاً |

### الإخراج والدمج

| المفتاح | النوع | القيمة الافتراضية | الوصف |
|---|---|---|---|
| `download_dir` | string | `"pdfs_{date}"` | قالب دليل تخزين PDF صفحة واحدة، `{date}` يتم استبداله بالتاريخ |
| `merged_filename` | string | `"人民日报-{date}-完整版"` | قالب اسم ملف PDF المدمج (بدون الامتداد) |
| `auto_merge` | bool | `true` | الدمج التلقائي في وضع يوم واحد |
| `keep_singles` | bool | `true` | الاحتفاظ بدليل PDF صفحة واحدة بعد الدمج؛ `false` = حذف تلقائي بعد دمج ناجح |
| `open_folder_after` | bool | `true` | فتح موقع الملف تلقائياً عند الانتهاء |

### إخراج النص

| المفتاح | النوع | القيمة الافتراضية | الوصف |
|---|---|---|---|
| `text_output_format` | string | `"TXT"` | تنسيق إخراج النسخة النصية: `TXT` / `DOC` / `DOCX` |
| `text_filename` | string | `"人民日报-{date}-文字版"` | قالب اسم ملف النسخة النصية (بدون الامتداد) |
| `text_include_edition` | bool | `true` | تضمين فواصل عناوين الصفحات في النسخة النصية أم لا |

### السجل والإشعارات

| المفتاح | النوع | القيمة الافتراضية | الوصف |
|---|---|---|---|
| `log_file` | string | `"rmrb_download.log"` | اسم ملف السجل؛ فارغ = لا سجل |
| `log_level` | string | `"normal"` | مستوى السجل: `quiet` / `normal` / `debug` |
| `beep_on_done` | bool | `false` | إصدار صوت تنبيه عند الانتهاء |
| `msg_on_done` | bool | `false` | عرض مربع رسالة Windows عند الانتهاء |

### الجدولة

| المفتاح | النوع | القيمة الافتراضية | الوصف |
|---|---|---|---|
| `auto_run` | bool | `false` | تفعيل التنزيل التلقائي اليومي (يتطلب أولاً تسجيل المهمة المجدولة بـ `--task-install`) |
| `auto_run_time` | string | `"08:00"` | وقت التنفيذ التلقائي اليومي `HH:MM` |

> قيم التكوين غير الصالحة (مثل حد سرعة سالب، تزامن خارج النطاق، رموز ألوان غير صالحة) يتم استعادتها تلقائياً إلى القيم الافتراضية عند البدء وطباعة تحذير، دون حدوث تعطل.

## تفاصيل التنزيل المجمّع

### تعبير نطاق التواريخ

يُدخل في واجهة BAT المجمّعة أو مع الوسيطة `--batch`. عدة مقاطع مفصولة بفواصل:

| التعبير | المعنى |
|---|---|
| `20260901-20260903` | 2026-09-01 إلى 2026-09-03 (شامل الطرفين) |
| `20260905` | 2026-09-05 فقط |
| `20260801-` | 2026-08-01 إلى **اليوم** (الطرف الأيمن فارغ) |
| `20260901-20260903,20260905` | نطاق + يوم واحد مجتمعان (إزالة التكرار التلقائي، الترتيب حسب التاريخ) |

- يجب أن تكون التواريخ تواريخاً موجودة فعلياً (مثل `20260134`, `20261301` يتم حظرها والإبلاغ عنها كخطأ)
- تاريخ البدء بعد تاريخ الانتهاء يسبب خطأ
- التواريخ بدون صفحات (غير منشورة/غير صادرة) يتم تخطيها تلقائياً وحسابها في الملخص

### وضع الدمج

| الوضع | السلوك | مثال اسم الملف الذي تم إنشاؤه |
|---|---|---|
| `each` | تنزيل ودمج منفصل لكل تاريخ | `人民日报-2026-09-02-完整版.pdf`, `人民日报-2026-09-03-完整版.pdf` |
| `all` | جميع صفحات جميع التواريخ مدمجة في **ملف واحد كبير عبر التواريخ** | `人民日报-2026-09-02-2026-09-03-完整版.pdf` |

النسخة النصية تدعم أيضاً `each` / `all`.

### تفعيل واجهة BAT المجمّعة

عدّل `config.json`، عيّن `"batch_enable"` إلى `true`. النقر المزدوج على BAT يدخل واجهة التنزيل المجمّع (إدخال النطاق → اختيار وضع الدمج → اختيار التنسيق).

## تنسيقات إخراج النسخة النصية

| التنسيق | الوصف | التبعية |
|---|---|---|
| `TXT` | نص عادي UTF-8، يتضمن عناوين الصفحات ونصوص المقالات | لا شيء |
| `DOC` | محتوى HTML محفوظ كـ `.doc`، يمكن فتحه مباشرة بـ Microsoft Word / WPS | لا شيء |
| `DOCX` | OOXML قياسي (هيكل مستند أدنى مكتوب يدوياً بـ `zipfile`)، يمكن فتحه بـ Word/WPS/LibreOffice | لا شيء |

بدّل التنسيق عن طريق تعيين `"text_output_format": "DOCX"` إلخ في `config.json`.

## الأخطاء الشائعة والحلول

| رسالة الخطأ | السبب | الحل |
|---|---|---|
| `未来日期，人民日报尚未出版` | تم إدخال تاريخ بعد اليوم | تحقق من التاريخ، أو عدّل `default_date` |
| `日期不存在（月份或日期越界）` | مثل `20261301`, `20260134` | أدخل تاريخاً موجوداً فعلياً |
| `日期应为 8 位数字 YYYYMMDD` | عدد أرقام التاريخ غير صحيح | أدخل بتنسيق `YYYYMMDD`، مثل `20260903` |
| `未找到任何版面` | تاريخ غير منشور/غير صادر، أو `edition_filter` أفرغ الصفحات، أو شذوذ في الشبكة | بدّل إلى تاريخ يوم عمل؛ تحقق من `edition_filter`؛ راجع مطالبة `[网络]` أعلاه |
| `无法安装合并库 pypdf` | الشبكة غير متاحة، لا يمكن التثبيت عبر pip | نفّذ `pip install pypdf` يدوياً، أو أعد المحاولة بعد تكوين الوكيل |
| `合并失败：目标文件正被占用` | PDF بنفس الاسم مفتوح في قارئ PDF / معاينة Explorer | أغلق الملف بنفس الاسم المفتوح وأعد المحاولة، أو عدّل `merged_filename` / `download_path` |
| `域名解析失败 / 网络连接失败` | الشبكة غير متصلة، شذوذ DNS أو خطأ في الوكيل | تحقق من الشبكة؛ تحقق من تكوين `proxy` في `config.json` |
| `连接/读取超时` | الشبكة بطيئة أو استجابة الخادم بطيئة | زد `timeout` (مثل 60)، أعد المحاولة لاحقاً |
| `服务器返回 HTTP 403/429` | وصول متكرر جداً، حد معدل | زد `request_interval` (مثل 1.0)، قلّل `concurrent` |
| `日期表达式错误：无效日期` | تعبير مجمّع يحتوي على تاريخ غير صالح | أدخل بتنسيق `YYYYMMDD`، افصل عدة نطاقات بفواصل |
| `格式参数应为 text / pdf / both` | وسيطة التنسيق غير صحيحة | استخدم `text` / `pdf` / `both` (واجهة BAT: T / PDF / B) |
| `--merge-mode 应为 each / all` | وسيطة وضع الدمج غير صحيحة | استخدم `each` أو `all` |

## إخلاء المسؤولية

- هذه الأداة **مخصصة للاستخدام الشخصي في التعلم والبحث فقط**، ولا يمكن استخدامها لأي نشاط تجاري.
- حقوق الطبع والنشر لـ 《صحيفة الشعب اليومية》 تعود إلى مؤسسة صحيفة الشعب اليومية. يجب على المحتوى الذي تم تنزيله الامتثال للقوانين ذات الصلة وشروط استخدام الموقع.
- يرجى التحكم بشكل معقول في وتيرة الوصول (`request_interval`) لتجنب إثقال كاهل الموقع الرسمي.
- إذا تغيرت بنية الموقع الرسمي، فقد تتطلب هذه الأداة تعديلات مقابلة.
